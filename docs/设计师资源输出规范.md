# 设计师资源输出规范

> 适用对象：为主题包提供视觉资源的设计师
> 核心原则：**设计师不需要手写最终文件名**。包名映射、分层命名、格式转换全部由 ThemePackager 完成。

---

## 一、总流程

```
项目方提供适配应用清单 ──► 设计师按清单出图 ──► 工具绑定/识别/归位 ──► 校验 ──► 打包 .xth
        （唯一事实来源）        （简单命名即可）        （自动命名 <包名>_bg.webp 等）
```

**适配应用清单**是项目级文件，包含每个应用的：应用名、包名、预装/三方分类、适配要求。
设计师对照清单出图；清单内没有适配到的应用，手机端会按兜底模板（mask 合成）自动处理。

> 清单中应用名（name）未补全的条目，不影响"工具内绑定"和"按包名命名"两种交付方式，
> 只影响"按应用名命名"的匹配。可用 `node core/cli.js list:check <清单.json>` 查看待补清单：
> 系统应用优先补，三方应用按需补，特殊资源无需补。

## 二、应用图标：设计师要交什么

### 2.1 绑定方式（三选一，推荐 A）

| 方式 | 设计师操作 | 说明 |
|:---:|---|---|
| **A** | 在工具的清单条目上直接拖入设计稿 | 推荐，零歧义 |
| **B** | 文件名按包名命名：`com.tencent.mm` | 包名必须与清单一字不差 |
| **C** | 文件名按应用名命名：`微信` | 工具自动匹配清单，重名/歧义时需人工确认 |

> 匹配只看文件名的**名称部分**，扩展名不限（.png / .jpg / .webp 均可）。
> 注意：这只是**交付源文件**的命名——主题包内的最终产物**一律是 webp**，由工具在打包时强制转换，设计师无需手动转格式。
> 同一个主题项目内请统一用一种方式，不要混用。

### 2.2 按主题风格交付

| 主题风格 | 每个应用交付 | 画布尺寸 | 说明 |
|---|---|:---:|---|
| normal（非自适应） | 1 张完整图标 | 162 × 162 | 所见即所得，直接显示 |
| adaptive（自适应） | 2 张：前景 + 背景 | 324 × 324 | 前景为主体图形（四周留安全区），背景为底色/底形 |
| mono（可着色） | 前景 + 背景 + 1 份 SVG | 324 × 324 | SVG 用于生成 monochrome 上色资源，要求见 2.3 |

- 前景/背景两张图在文件名上无需区分后缀，工具内绑定时分别拖入"前景层 / 背景层"即可；
  若按文件命名交付，则用 `<名称>_bg`（背景）、`<名称>_top`（前景）区分
- 交付源文件格式 png / jpg / svg 均可；**主题包产物一律 webp，工具打包时强制转换**（这条是硬规则，包内不允许出现非 webp 图片）
- 动态时钟（时针/分针/背景/中心点）、文件夹图标、小部件图标属于特殊资源，在工具中单独入口导入

### 2.3 mono 主题 SVG 的硬性要求

monochrome 最终是运行时直接解析的 VectorDrawable，**主题包不参与 apk 编译**，因此 SVG 中：

- 只允许：纯路径图形（path）、纯色填充/描边、基础变换（translate / scale / rotate）
- 不允许：渐变、滤镜、蒙版、图片嵌入、文字元素、外部引用——这些在 VectorDrawable 中需要 aapt 编译期能力，运行时无法解析
-  SVG 画布建议 108 × 108 viewport，有效图形居中于 66 × 66 安全区内

不合规的 SVG 会在导入时被工具**直接拒收并指出具体元素**，不会进入主题包。

## 三、其他资源交付

| 资源 | 交付方式 | 规格 |
|---|---|---|
| 桌面壁纸 | 1 张，工具内"壁纸"入口导入 | 建议 ≥ 1080×2400，竖版 |
| 锁屏壁纸 | 1 张，同上 | 同上 |
| 预览图 | 锁屏 1 张起 + 桌面若干张（数量不限） | 真机截图或效果图，竖版 |
| 主题缩略图 | 可选，1 张 | 方形，600×600 |
| 字体 | .ttf / .otf 文件 | 数字字体、日历星期字体等，工具内分类导入 |
| 兜底模板 | 背景 1 张 + 前景 1 张 + 蒙版 1 张 | 与图标同风格，蒙版为裁切形状（alpha 通道生效） |
| 图标风格预览图 | 1 张 | 展示数个代表图标的合成效果 |

## 四、交付后工具给出的报告

导入完成后，设计师能在工具里看到：

1. **绑定结果**——每张图对应到哪个应用，有无歧义待确认
2. **覆盖率**——清单内哪些应用已适配、哪些未适配（未适配的将走 mask 兜底，可预览兜底效果）
3. **校验结果**——尺寸、格式、配对、SVG 合法性等问题清单，点击可定位

确认无误后一键导出 .xth，全程不需要接触文件夹结构。

## 五、常见错误（工具会拦截）

- 包名手误：清单内不存在的包名 → 拒收并提示相近条目
- adaptive 主题只交了前景没交背景 → 报"缺背景层"
- mono 主题缺 SVG 或 SVG 含渐变等非法元素 → 拒收并指出元素位置
- 图标尺寸错误、jpeg 改后缀伪装 png → 告警并自动修正
